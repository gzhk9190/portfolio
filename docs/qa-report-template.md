# Bug Report Template

| Field | Details |
|---|---|
| **Title** | Short, specific summary (what broke and where) |
| **Environment** | Browser + version, OS, device/screen size, app URL, date |
| **Preconditions** | State required before starting (logged in, empty cart, etc.) |
| **Steps to reproduce** | 1. … 2. … 3. … |
| **Expected result** | What should happen |
| **Actual result** | What happened instead |
| **Severity** | Critical / Major / Minor / Trivial |
| **Evidence** | Screenshot, screen recording, console/network log |
| **Suggested fix** | Optional idea, clearly marked as a suggestion |
